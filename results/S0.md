# S0 — The hard eval, and honest baselines for the S-track

**Ran:** 2026-08-31 · plan: `.claude/plans/ship-model-track.md` · eval CPU,
llama.cpp, unconstrained decoding (per the R2 grammar finding).

## What was built

- **Multi-domain worldgen:** theme-pack schema + compiler
  (`data/gen/domains.py`); 143 domains, all passing the 11-level reference
  gauntlet (142 initial + `coursebuilder`, modeled on real mobi-cbiv
  request patterns). 41 domains reserved **eval-only forever**
  (`data/holdout/reserved_domains.json`), 102 for training.
- **Suites** (deterministic seeds, regenerable):
  - `E-known` — the R1 1,000-task set (in-distribution reference).
  - `E-foreign` — 500 tasks, reserved domains only (seed 31001).
  - `E-crowded` — 300 tasks with 25–70 distractor tools from donor
    domains merged into context (38–78 tools total; seed 31002).
  - `E-ood-english` — 200 E-foreign tasks rewritten meaning-preservingly
    into 5 human styles (terse/chatty/typos/corporate/narrative);
    identical expected states, so paired scoring is exact.
- **Real-request annex:** 361 scrubbed `ai.AgnoSessions` prompts
  (agentId `mobi-cbiv`) staged for owner PII review (scratchpad only).
  Observation: real workload is heavy on per-item content transformation
  ("proofread every module") — maps to `FOREACH → CALL <transform-tool>`;
  planner still owns selection/scoping, but shipped tool vocabulary
  matters as much as planner accuracy.
- **imatrix quant tooling:** calibration file from the training
  distribution (`baselines/qwen/calibration_v1.txt`), llama-imatrix +
  Q4_K_M requantize of the Q8 checkpoint (BF16 originals were not kept;
  requantized-from-Q8 noted).

## Findings

1. **The ship-without-retraining gap is ~35 points, and it decomposes:**
   domain novelty −23 (86 → 63 going from same-style holdout to 41 real
   domains), human phrasing −5 paired at 0.8B (and ~0 at 2B — the 2B is
   phrasing-robust: 69.5 → 72.5 on rewrites), and **crowding −40**: at
   38–78 tools the 0.8B compiles only 28% of programs. Tool selection at
   scale is the dominant failure mode, bigger than domain novelty.
2. **Scale profile:** +7 on E-foreign, +13 on E-crowded, phrasing
   robustness — 2B buys grounding and robustness, nothing
   in-distribution.
3. **Ambiguous scope (L9) is dead on unseen domains at any size** (2/24
   and 3/24). This is a PAUSE-and-confirm product mechanism, not a model
   capability to chase.
4. **Level pattern under crowding:** even L1 simple chains collapse
   (0/14 at 0.8B) — the failure is symbol selection in a long context,
   not program complexity. PARALLEL (L7) is worst-hit at both sizes
   (1/35, 3/35).
5. imatrix-Q4 lossless on this distribution → the quant column starts
   free; watch for the rung where that stops being true.
