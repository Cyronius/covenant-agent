Agent Core — browser inference stand-in

Dev-only POC. Loads the R2 Condition-B GGUF model via wllama (llama.cpp compiled to WASM/WebGPU), generates a grammar-constrained Agent Core program client-side, and round-trips it through the existing Python parse/typecheck/effects/compile/execute pipeline via a local dev server. See .claude/plans/browser-inference-standin.md. Not a shippable artifact — the model is ~2.7× over the browser size budget (PLAN.md §0).
